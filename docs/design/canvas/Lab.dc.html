Break it

Drop the header A proxy strips traceparent. The second service opens a trace of its own.
Flip the flags Sampled bit off. The span still exists; nothing records it.
Zero the span id An all-zero id is invalid by spec. Watch the parser refuse it.

Each failure is armed, not described. You click it and the model breaks in front of you.

Why it works this way

The W3C Trace Context specification defines exactly one required header. It carries a version, a 16-byte trace id, an 8-byte span id and one flag byte — and nothing else. There is no room in it for a service name, a timestamp or an attribute, which is the point: it is the smallest thing that can survive an arbitrary number of hops through software that has never heard of it.

Everything else about the trace is reconstructed at the backend, by matching ids that were generated independently on machines that never spoke to each other.
