# Prints do Cisco Packet Tracer

Capturas reais de `labs/telecentro-network/entrega/telecentro-equipe-10.pkt`,
uma por teste do PDF de entrega (`teste-N-*.png`), mais a topologia
(`topologia.png`). O lab usa as mesmas imagens, uma por capítulo, pelo mapa
`PRINTS` em `apps/site/src/components/RedeModos.tsx`.

O que cada print mostra está em `labs/telecentro-network/README.md`, seção 4.

A vista física (`fisica-cidade`, `fisica-planta`, `fisica-rack-telecentro`,
`fisica-rack-provedor`) é capturada da vista *Physical* do mesmo `.pkt`; os
racks são duas capturas do canvas juntas na vertical, sem edição.
