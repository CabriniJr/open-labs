# Prints do Cisco Packet Tracer

Um print por capítulo do lab `labs/telecentro-network`, com estes nomes:
`network.png`, `dhcp.png`, `dns.png`, `http.png`, `nat.png`, `acl.png`, `ssh.png`.

Depois de salvar, registre o arquivo em `PRINTS`
(`apps/site/src/components/RedeModos.tsx`), por exemplo `{ dhcp: "dhcp.png" }`.
O que tirar em cada um está em `labs/telecentro-network/README.md`, seção 4.
